# 文件夹递归导入

在“上传文档”页面先选择所属文档集及大模型整理模式，再点击“选择文件夹”。浏览器会列出所选目录及所有子目录中的文件；页面展示有效候选文件、跳过数量和具体原因。有效文件默认勾选，可逐项取消、全选待上传或取消全部；预览支持按文件名/相对路径搜索及 20/50/100 项分页，跨页勾选会保留。点击“开始上传”才会调用现有 `/documents/upload` 接口，不会因选择目录就发送文件。搜索只影响预览，上传所有已勾选的待上传文件。

支持 PDF、DOC/DOCX、PPT/PPTX、XLS/XLSX、Markdown、TXT，扩展名大小写不敏感。过滤 `.DS_Store`、`__MACOSX`、AppleDouble `._*`、`Thumbs.db`、`Desktop.ini`、隐藏文件/目录、`node_modules`、Office `~$*`、常见临时/备份文件、空文件及超过 50 MB 的文件。筛选只确认是否值得尝试解析，不能证明文件未损坏、未加密或内容可读；最终仍由现有探测和解析流程判定。

每批固定使用开始时的账户、文档集和整理设置。逐份上传并等待后台处理结束，再提交下一份；单份入库失败后继续。已提交但无法查询状态时暂停后续提交，避免连接异常时继续积压。点击“停止后续上传”保留已经提交的后台任务，未提交文件保持待上传，可继续本次队列。站内切换页面保留上传组件和队列，后续文件继续逐份提交；其他页面顶部显示批量处理状态，点击可返回上传页查看进度。退出登录停止后续文件提交；刷新或关闭浏览器页面会丢失尚未提交的文件队列。已提交文件按后端服务生命周期继续处理，重新登录后可查文档列表。

相对路径保存在原入库任务的 `options_json.source_relative_path`，首次写库时附加到分块 metadata；LLM 重新写库会保留已有 metadata。该字段只用于溯源，经过后端校验，不用作磁盘写入路径。实际存储沿用用户目录内 UUID 文件名，不同子目录的同名文件不会覆盖。文档列表仍采用原有平面文档结构，不自动把子目录转成新的文档集。

同一次选择内，重复相对路径会在扫描时跳过。后端在保存上传字节后计算 SHA-256，检查同一上传者、同一目标文档集（包含未分组）内的相同大小及内容指纹；相同内容即使改名或位于不同子目录，也返回已有文档并跳过解析、LLM 和向量入库，不创建新任务，移除本次多余副本。重复时接口返回 HTTP 200、`duplicate=true`、已有文档 ID 和原因；新文档保持 HTTP 201。单文件上传与文件夹导入共用此保护。它避免重复入库和模型调用，上传字节仍需要发送到本地服务才能核验。

已有非失败文档缺少指纹时，按相同大小候选惰性计算并保存，不重新解析或整理。SQLite 上传检查及新文档/任务创建使用同一写事务，避免并发相同上传创建两份任务。失败文档允许重新上传；源文件缺失或大小不匹配的记录不阻止新上传。不同内容的同名文件分别入库；不同上传者或不同文档集保留独立记录和权限。判断针对完全一致的文件字节，重新导出、元数据变化或不同格式的相似正文不属于精确去重。历史重复记录不会自动合并、删除。

这里只导入已解压的目录，不自动解压 ZIP、RAR、7z 或嵌套压缩包。自动解压需要额外处理路径穿越、解压后体积、文件数量、嵌套深度及加密压缩包。浏览器只能读取用户选择的目录，不能根据输入的任意本地绝对路径自行扫描；空目录不作为文档导入。不支持目录选择的浏览器会提示使用原单文件上传。

有效文件预览可翻页查看全部结果，系统过滤的跳过明细最多展示前 100 条。预览不计算全文指纹，不调用 LLM。大模型整理费用及候选内容外发沿用已有上传设置，页面在开始按钮前提示。

文档列表支持文件名关键词搜索，文档集、LLM 状态、入库状态及格式组合筛选，再按 20/50/100 条分页。改变筛选回到第一页，刷新或删除后页码超出范围时回到最后有效页；切换页码或页大小会清空批量移动的本页选择。沿用权限过滤后的列表接口，当前分页在浏览器中完成，不改变问答检索文档范围，也不是正文全文搜索。数万文档规模需要后续改为服务端分页。

更多启动与配置见 [LOCAL_START.md](LOCAL_START.md)。本版合成测试覆盖跨页勾选、精确重复上传、列表筛选分页，以及切页继续/退出登录停止后续提交；没有以真实文档或付费模型做发布验证。
