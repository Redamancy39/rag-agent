请围绕下面这句话展开：

## 重点内容要求

请重点展开“文档预处理优化”：

- 为什么普通 RAG 直接按页或固定长度切块会失败
- 扫描件 PDF 无法直接提取文字，需要 OCR fallback
- 水印 PDF 会干扰 OCR，需要通过文本清洗和结构化整理降低影响
- 表格密集标准文件中，关键知识通常藏在表格行里
- 直接把表格读取成乱序文本会导致检索不到或答错
- 系统将表格转成“项目 + 条件 + 限量 + 单位 + 页码 + 来源文件”的事实化文本
- 对 OCR/表格低质量片段进行 LLM 归一化
- 通过质量评分、任务进度、错误信息让入库流程可观察
