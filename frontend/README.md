# Frontend

Vue 3 + Vite + TypeScript + Element Plus。页面包含上传、文档列表、文档集、知识问答、权限管理及系统配置，按账号权限展示入口。

## 开发与构建

```powershell
cd frontend
npm install
npm run dev
npm test
npm run build
```

默认页面端口 5173，后端为 http://127.0.0.1:8000。需要调整时，在未跟踪的 `.env` 设置 `VITE_API_BASE_URL`；只填写后端地址，不放服务端密钥。Windows 一键启动会固定使用本机 8000/5173。

Node.js 24 是本版前端逻辑测试与构建的验证环境；测试直接加载 TypeScript 工具文件，旧 Node 运行测试可能需要额外加载器。依赖版本见 `package.json`。

## 交互

- 主导航就地展开子项、箭头旋转、细竖线与错开淡入，同一时间只展开一组；上传入口优先。
- 文件夹预览支持勾选、搜索和分页，站内切页后继续串行上传，跨页显示批量状态。刷新、关闭或退出登录停止未提交文件，已提交任务仍在后端处理。
- 文档列表按名称、状态、格式、文档集与 LLM 检测/整理状态筛选，再在浏览器分页。
- 问答展示结论与依据，来源引用并入依据；范围和参数可折叠，支持四档胶囊、数值调整、偏好恢复和每次任务参数快照。
- 本地食品术语预检采用防抖与取消过期响应，建议采纳校验当前问题和 Unicode 位置；普通账号也可查看可搜索热词表。

后端仍负责 JWT 和权限过滤，前端隐藏入口不能替代接口授权。检索参数偏好按账号保存于本浏览器，不跨设备同步。

本版前端 15 项逻辑测试、类型检查和生产构建通过，合成 UI 验证通过；现有大 bundle 提示仍需后续按路由/组件拆分优化。该开发服务器不代替生产部署。
